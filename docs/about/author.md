## How to cite

If you use Agentic-SpliceAI in your work, please cite it. The repository
includes a [`CITATION.cff`](https://github.com/pleiadian53/agentic-spliceai/blob/main/CITATION.cff)
file, so GitHub also offers a **"Cite this repository"** button on the
[project page](https://github.com/pleiadian53/agentic-spliceai).

**Plain text**

> Chiu, Po-Hsiang (Barnett). (2026). *Agentic-SpliceAI: An open-source framework
> for adaptive splice-site prediction and novel isoform discovery* (Version 0.1.0)
> [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.21696681
